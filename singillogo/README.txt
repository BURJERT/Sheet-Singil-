HOW TO CHANGE THE FAVICON / APP ICON
====================================
Replace the files in this folder with your own image. KEEP THE SAME FILE NAMES.

  singillogo-32.png    32 x 32 px    browser tab icon
  singillogo.ico       16/32/48 px   older browsers and Safari
  singillogo-180.png   180 x 180 px  iPhone/iPad home screen icon
  singillogo-192.png   192 x 192 px  Android/installed-app icon
  singillogo-512.png   512 x 512 px  Android/installed-app icon (large)

Use a square image. Free tool to make all sizes from one picture: https://realfavicongenerator.net
After replacing, upload to GitHub, then hard refresh (Ctrl+Shift+R).
If browsers keep showing the old icon, change ?v=7 to ?v=8 in the icon lines of index.html.
