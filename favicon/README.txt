HOW TO CHANGE THE FAVICON
=========================
Replace the files in this folder with your own image. KEEP THE SAME FILE NAMES.

  favicon-32.png        32 x 32 px    browser tab icon
  apple-touch-icon.png  180 x 180 px  iPhone/iPad home screen icon
  icon-192.png          192 x 192 px  Android/installed-app icon
  icon-512.png          512 x 512 px  Android/installed-app icon (large)
  favicon.svg           optional vector icon. If you only have PNG files,
                        delete favicon.svg AND delete the line in index.html that
                        mentions favicon.svg (inside the "ADD YOUR FAVICON IMAGE HERE" block).

Use a square image (ideally with a plain or transparent background).
Free tool to make all sizes from one picture: https://realfavicongenerator.net
After replacing, upload to GitHub, then hard refresh (Ctrl+Shift+R).
